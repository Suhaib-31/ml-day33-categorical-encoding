# Day 33 - Encoding Categorical Data

## Overview

This project demonstrates how to convert categorical data into numerical format for Machine Learning models.

Categorical encoding is a crucial preprocessing step because ML algorithms work with numerical values only.

---

## Features

- Label Encoding
- One-Hot Encoding
- Categorical Data Transformation
- Export Encoded Dataset

---

## Technologies Used

- Python 3
- Pandas
- Scikit-Learn

---

## Installation

```bash
pip install pandas scikit-learn
```

## Run

```bash
python main.py
```
